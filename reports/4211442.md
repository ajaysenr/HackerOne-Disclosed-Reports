## Program Summary

> ## Description

HackerOne community member Marcio Carvalho reported that a manager with access to two advertisers could link a tracker owned by one advertiser to a campaign owned by the other. The tracker-campaign page checked access to each object but did not compare their actual owners. The invalid association was persisted and processed for conversions, causing the first advertiser's tracker name and ID to appear in the second advertiser's restricted conversion report. Access to tracker reports or other data across agency boundaries was not demonstrated.

## Resolution

The tracker-campaign page now checks that the selected tracker's actual advertiser matches the advertiser in the campaign context before it accepts an association.

Security advisory: https://www.revive-adserver.com/security/revive-sa-2026-005
