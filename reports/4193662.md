## Program Summary

> ## Description

HackerOne community member Philip Sørensen reported spreadsheet formula injection through entity names in XLS report exports. A website user with zone-edit permission could store a formula as a zone name, which was then included in an advertiser's Conversion Tracking report. Managers could also supply entity names that appeared in other users' exports. Opening an affected XLS file could evaluate attacker-controlled formulas and alter the displayed report contents. This bypasses the field-specific fix for CVE-2026-108563, which protected tracker-variable values but left other text fields exposed. Data exfiltration and operating-system command execution have not been established.

## Resolution

The shared XLS report writer now writes ordinary text as literal string cells, including entity names, report titles, headers and parameters. Formula and hyperlink cells require explicit opt-in by report plugins. Numeric and date columns retain numeric output.

Security advisory: https://www.revive-adserver.com/security/revive-sa-2026-005
