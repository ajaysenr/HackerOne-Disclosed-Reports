## Vulnerability Details

##Summary:  

Any attacker with a low privilege account can exploit an authenticated boolean/timebased/error based SQL injection to extract sensitive data or execute malicious sql query
note: since essity is an openscope, i assume this domain is related to essity because the domain "████████" is linked to ████████ a brand owned by Essity

1 - create a low privilege account on "████████"
2 - execute a POST request at "████████", the vulnerable parameter will be "orderNo"
