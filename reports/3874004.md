## Vulnerability Details

## Summary

Weblate passes the configured component template filename to `hg cat` without an option terminator:

```python
return self.execute(
    ["cat", "--rev", revision, path],
    remote_op="none",
    needs_lock=False,
    merge_err=False,
)
```

Component.template accepts relative filenames beginning with -. Mercurial therefore interprets an option-shaped template filename as command-line configuration instead of a repository path.

The production Update RESX files add-on passes component.template directly into this sink after a repository update:

```python
content = component.repository.get_file(
    component.template,
    previous_head,
)
```

Using Mercurial's --config=alias.cat=!<command> syntax, an attacker can replace hg cat with a shell alias and execute commands as the Weblate service account.

This appears to be an incomplete fix for CVE-2022-23915 / GHSA-3872-f48p-pxqj. The Weblate 4.11.1 fix hardened several Mercurial argument paths but did not fix HgRepository.get_file().

## Affected versions

The residual vulnerability was confirmed in:

* Weblate 4.11.1, the first release containing the CVE-2022-23915 fix.
* Latest PyPI release 2026.7.1.
* Current main commit 76d311849a56c99cfc68968827a7cf9a13af3551.

The underlying sink and reachable caller first appeared in Weblate 2.19. Versions before 4.11.1 are already covered by CVE-2022-23915. Therefore, the incomplete-fix range is 4.11.1 through the current release and main.

## Preconditions

The component must:

1. Use Mercurial.
2. Use RESX.
3. Contain an option-shaped template filename.
4. Have the Update RESX files add-on installed.
5. Process a later repository update.

The integration proof demonstrates that a non-superuser, non-staff account with project-scoped component.edit can set the template and install the compatible add-on through the real API even though management.addons is false.

The add-on permission behavior is included only to prove reachability; I am not reporting it as a separate vulnerability.

## Expected behavior

Repository filenames must be placed after an explicit -- option terminator. An option-shaped filename must be handled as a literal path and must never alter Mercurial configuration or command dispatch.

## Observed behavior

The accepted component template reaches Mercurial before an option terminator. Mercurial evaluates it as --config, invokes the controlled shell alias as the Weblate service account, reads the synthetic file, and returns success from the normal RESX update.

## Recommended remediation

Fix HgRepository.get_file() as follows:

```python
return self.execute(
    ["cat", "--rev", revision, "--", path],
    remote_op="none",
    needs_lock=False,
    merge_err=False,
)
```

I also recommend auditing every Git and Mercurial call containing repository-derived path arguments and adding a regression test using an option-shaped tracked filename.

## Prior issues and duplicate review

This is not the same as CVE-2026-24126, which involved admin-only ssh-keyscan argument injection and file disclosure through /manage/ssh/.

This report concerns HgRepository.get_file(), a project-scoped component editor, the RESX update path, and command execution through a Mercurial alias.

I found the original CVE-2022-23915 hardening PR but no public report covering this missed get_file() sink.

## Safety statement

Testing used only local source, official packages and containers, temporary repositories, ephemeral databases, and researcher-created synthetic data. No Hosted Weblate instance, third-party data, credentials, or system file such as /etc/passwd was accessed.

## Impact

An authenticated user with project-scoped component-edit permission can cross the intended Weblate authorization boundary and execute operating-system commands with the privileges of the shared Weblate service account.

Depending on deployment configuration, this can expose or modify repositories, application data, environment-provided credentials, signing material, translation artifacts, or other resources accessible to the Weblate process. It may also allow tampering with repository contents or generated translation output.

The safe proof demonstrated repeatable command execution as `uid=1000(weblate)` and reading of a researcher-created synthetic file. It does not claim root execution. The exact `--` delimiter fix prevented the effect while preserving the normal repository update.
