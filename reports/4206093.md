## Program Summary

> ## Description

HackerOne community member 0xE2E reported that a manager could supply another agency's advertiser or website ID as a report scope and receive the corresponding name in the exported XLS header. The report form displayed only permitted entities, but the submitted scope IDs were not checked against that list. The demonstrated disclosure was limited to entity names; the tested report's data query remained agency-filtered.

## Resolution

The shared report scope field now accepts advertiser and website IDs only when they appear in the current account's permitted selections. This covers the Live Campaign Delivery, Advertising Analysis and Conversion Tracking reports.

Security advisory: https://www.revive-adserver.com/security/revive-sa-2026-005
