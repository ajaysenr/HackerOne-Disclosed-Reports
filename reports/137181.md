## Program Summary

> ThisData made inappropriate use of the user-supplied host header, which could have resulted in a user being redirected to an arbitrary domain under some circumstances. On other pages, the header was used within metadata values like the canonical URL. 

7H0R4PP4N was very thorough and helpful as we resolved this issue!
