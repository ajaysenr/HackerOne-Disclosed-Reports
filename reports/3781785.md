## Vulnerability Details

## Summary:
A reflected HTML injection vulnerability was identified on the ████████████████ login page. The page includes a custom JavaScript theme script that reads the URL parameters infotext and signintext and inserts them into the DOM using innerHTML.

An attacker can craft a link to the ████████ endpoint that injects arbitrary HTML into the authentication page (for example, adding phishing instructions and an attacker-controlled link). This can be abused for UI redress and credential phishing against users attempting to sign in to the relying party (for example, ████████).

## Steps To Reproduce:
Endpoint - https://████████/adfs/ls

Open the following endpoint with HTML injection payload in the browser
```
https://████████/adfs/ls?wa=wsignin1.0&wtrealm=https%3A%2F%2Fwww.████████.ro%2Fconnect&whr=AD%20AUTHORITY&portalui=████████extdev&signintext=SIGNIN_MIN_93470&infotext=%3Ch2%20id%3Dphish93470%3ESecurity%20notice%3C%2Fh2%3E%3Cp%3EContinue%20to%20verify.%3C%2Fp%3E%3Ca%20id%3Dlink93470%20href%3Dhttps%3A%2F%2Fexample.com%2F%3EContinue%3C%2Fa%3E
```
████████
The string SIGNIN_MIN_93470 appears in the login message area and new “Security notice” header and a “Continue” link appear below the login form. Confirming that HTML was injected via the URL input paramter.
████████
Hovering over the “continue” button leads to an arbitrary attacker domain(example.com). Clicking on continue button will redirect us to the external website
████████

Note - Even though the ████████ subdomain is out of scope, it drastically increase the risk to the ████████customers when provided with the above link which belongs to ████████. Putting customers in direct threat of credential harvesting, fake pages, brand reputation damage.

## Impact

The issue enables attacker-controlled content to be rendered on a live authentication page used for federated sign-in. This can be used to:
Cause users to follow attacker-controlled links presented as part of the legitimate login page (phishing / malware delivery).
Capture credentials by socially engineering users into entering credentials into attacker-injected content (e.g., injected form elements or instructions).
