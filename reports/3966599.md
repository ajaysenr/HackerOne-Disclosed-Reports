## Vulnerability Details

**Description:** 
The unauthenticated go-httpbin instance exposes multiple endpoints that accept attacker-controlled input without appropriate validation.

Two issues were identified:
1. Cross-subdomain cookie tossing / cookie injection - `/cookies/set` allows an unauthenticated user to specify an arbitrary cookie `Domain`, including the parent `aws.dev` domain. This allows attacker-controlled cookies set from one `*.aws.dev` host to be delivered to unrelated sibling applications.
2. Open redirect - `/redirect-to` accepts an arbitrary URL and redirects the victim to that destination without validation.

The cookie issue was verified against unrelated `*.aws.dev` applications. A crafted cookie value was also observed to cause a separate application at `████████` to receive a CloudFront/WAF 403 response, demonstrating a practical cross-tenant denial-of-service impact.

## Impact

## Summary:
* Cross-subdomain cookie injection/tossing: Plant attacker-controlled cookies scoped to `*.aws.dev`, causing them to be sent to unrelated sibling applications.
* Denial of service: Crafted cookie values can trigger CloudFront/WAF filtering and make affected applications inaccessible to the victim.
* Potential cookie shadowing: Attacker-controlled cookies may interfere with security or application cookies used by sibling applications.
* Open redirect: Redirect users from a trusted `aws.dev` URL to an attacker-controlled external destination.
