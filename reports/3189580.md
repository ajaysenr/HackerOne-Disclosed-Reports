## Vulnerability Details

## Summary:

The password reset functionality accepts the user's current password as the new password without any validation or rejection. This bypasses common password policy controls and weakens account protection, especially when combined with session hijacking or stealth access persistence.


## Steps To Reproduce:

1) Login to an existing account using valid credentials.

2) Initiate a password reset (via "Forgot Password" or "Change Password" flow).

3) When prompted to enter a new password, submit the same password currently in use.

4) Observe: The password is accepted successfully without any error or warning.

--Optionally, re-login using the same password to confirm that the reset succeeded using the same credentials.
