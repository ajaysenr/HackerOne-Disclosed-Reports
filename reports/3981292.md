## Program Summary

> After a domain migration, Basecamp's embed display page rendered provider-supplied HTML on the application origin instead of the isolated embeds host, so a crafted embed could run script as another account's signed-in user.

We made that check fail closed, so embed HTML renders only on the embeds host, and we now rebuild provider frames from the media id alone, so options in a pasted URL no longer reach a third-party player.

Thanks to deivizzzz for a thorough, well-documented report.

## Vulnerability Details

## Summary

`/:account/embeds/:sgid/full` renders attacker HTML verbatim and answers unauthenticated under account ids unrelated to it. Loading Basecamp's own Turbo bundle from an allowlisted CDN makes Turbo stamp the victim's CSP nonce onto my script.
