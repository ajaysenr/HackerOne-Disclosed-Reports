## Program Summary

> We consider this a non-issue due to the nature of the developer configuration flag `allow_local_remote_servers` being here exactly for that case. For developers it's necessary to test with local servers, so when this flag is allowed of course the "internal SSRF" works.
If the configuration is not set or set to false as it should be on any production server, no SSRF is possible.
