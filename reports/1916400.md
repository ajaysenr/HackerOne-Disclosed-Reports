## Program Summary

> On some paginated pages, if a page number was provided in the URL that was larger than the number of pages available, then internal logic would result in an infinite loop generating markup on each pass through the loop. By correcting the logic it was trivial to correct this case and avoid generating links to pages that don't exist.
