## Vulnerability Details

## Summary

Hello team,
The WordPress media library on ████████ exposes 29 ZIP archives containing premium (paid) plugin packages. These files are accessible without authentication via direct URL and are indexed by the WordPress REST API (`/wp-json/wp/v2/media`). The archives contain full plugin source code and embedded license/purchase verification tokens. An attacker can download these packages, extract license keys for unauthorized use, and analyze the source code to develop targeted exploits against the site.

## Steps to Reproduce

### Step 1  Enumerate ZIP files via REST API
```bash
curl -s "https://████████/wp-json/wp/v2/media?per_page=100&media_type=application" \
  | python3 -c "
import sys, json
for m in json.load(sys.stdin):
    url = m.get('source_url','')
    if '.zip' in url: print(url)
"
```

### Step 2  Download any package without authentication
```bash
curl -O "https://████████/wp-content/uploads/2025/10/revslider-6.5.14-HcwXam9CAYQZ0Y5.zip"
# HTTP 200  7.6 MB downloaded successfully
```

### Step 3  Extract and inspect for license keys
```bash
unzip revslider-6.5.14-HcwXam9CAYQZ0Y5.zip
grep -r "purchase_code\|license\|api_key\|activation" revslider/
```

## Remediation
1. **Delete all ZIP files** from the uploads directory immediately
2. **Revoke and rotate** all license keys embedded in the exposed packages
3. **Block direct access** to ZIP files in the uploads directory via nginx/Apache configuration:
   ```nginx
   location ~* /wp-content/uploads/.*\.zip$ {
       deny all;
   }
   ```
4. Use a dedicated update mechanism (e.g., Envato Market plugin) instead of uploading plugin ZIPs through the media library

## Impact

- **License key theft**  premium plugin license keys (RevSlider, Wordfence Premium, ACF Pro, Ultimate Elementor) can be extracted and reused, causing financial loss
- **Source code analysis**  full plugin source enables targeted vulnerability research against this specific site's software stack
- **Version history disclosure**  29 packages spanning 2019–2025 reveal the exact upgrade timeline, allowing an attacker to identify windows where known CVEs were unpatched
- **Supply chain risk**  if these packages were obtained from unofficial sources, they may contain backdoors
