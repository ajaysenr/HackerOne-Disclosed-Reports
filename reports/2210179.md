## Program Summary

> Improper access control in all versions of GitHub Enterprise Server allows unauthorized users to view private repository names via the "Get a check run" API endpoint. This vulnerability did not allow unauthorized access to any repository content besides the name.
[CVE-2023-46646](https://nvd.nist.gov/vuln/detail/CVE-2023-46646)
